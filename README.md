# 组合活动 · 页面状态连线图

双击同目录 `index.html` 即可离线打开，无需安装。

四组共12个状态：政策页（正常、未开始、已结束）、登录弹窗、抽奖页（待抽奖、中奖、未中奖）、领券结果页（五种情况）。沿箭头查看页面关系，无需点击原型业务按钮。

拖拽平移，滚轮缩放；顶部可定位四类页面，底部“全图”回到总览。卡券长页面完整铺开，静态截图中的按钮不响应业务操作。

这是一份本地评审示意，不连接真实账号、车辆、抽奖或发券接口。领取结果页的五种情况互斥展示，认证级示例为方便看图采用全部展开视图，实际默认折叠规则未改。

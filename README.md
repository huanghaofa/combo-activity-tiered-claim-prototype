# 组合活动分级领取原型

打开 `index.html` 查看全场景导航，或由场景卡片进入 `activity.html`。

这是静态交互演示，使用模拟的身份、VIN、人群、活动与卡券数据。不会调用真实登录、oneID、发券、抽奖或激活接口，刷新将恢复场景初始状态。领券中心和卡券使用仅为跳转示意。

当前演示包括：等级与人群条件、部分/零领取、独立抽奖及防重、组合活动时间、子活动未开始、券过期、升级返回、已领活动折叠、图片券未解锁展示及资格异常。认证、绑车分组不折叠；已领券可直接使用，无激活步骤。

运行不需要服务器、构建或安装依赖，资源均为相对本地路径；也可作为 GitHub Pages 静态页面发布。不同设备的实际显示仍需按目标环境复核。

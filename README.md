# 2026年9月活动中心与卡券中心原型

打开根目录 `index.html`，可进入四套独立静态原型：

- `combo-activity/`：组合活动分级领取页面状态连线图及业务流程。
- `retention-activity/`：保客活动创建准入联动交互原型与评审资料。
- `coupon-product-maintenance/`：卡券商品维护，包含商品选择、上传模板和关联SKU直接导出。
- `coupon-instance-void/`：卡券实例作废与角色权限配置。

页面全部使用相对路径，无需构建。公开页面只用于产品和研发评审，使用虚构数据，不连接真实业务接口。

原仓库既有非入口文件和旧深链接继续保留；本次仅新增两个卡券中心目录并更新九月总导航。

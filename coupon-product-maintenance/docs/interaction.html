SKU导出与投放后商品维护

需求DFN-REQ-20260916-001，功能7/8；当前版本V1.1，2026-09-16。批注修订任务DFN-20260916-004。

1. 本轮已确认页面

  • 适用商城商品区不提供“SKU / 商品分类”单选，展示“已关联X个商品”。
  • 保留“选择商品”“上传文件”“下载模板”“导出已关联商品”四个入口。
  • 原“已保存成功SKU / 下游同步成功SKU / 保存版本 / 已保存批次”汇总块整体隐藏，不留下空容器。
  • 点击“导出已关联商品”直接下载商品SKU列表，无导出弹窗、范围选择、成功口径或格式选项。
  • 导出文件仅一列sku_id，每个已关联商品SKU一行，不附模板ID、关系版本、导出时间等字段。本轮使用CSV真实下载。
  • 已投放模板可以进入商品维护；其他业务字段保持只读。查看与商品维护保持独立。

2. 页面与交互

列表 → 商品维护 / 查看 → 适用商城商品。

动作行为
已关联商品数本原型显示模板已保存关联集合的数量；草稿另行提示待新增，保存后更新数量
选择商品打开虚构商品列表，可选择尚未关联的商品；确认加入草稿后需保存；已关联项只读保留
上传文件真实解析CSV，按虚构目录模拟处理；部分失败时只把成功项加入草稿
下载模板直接下载单列sku_id的CSV模板
导出已关联商品点击直接下载当前模板已保存关联SKU全量列表；不读原始上传文件和未保存草稿
无关联商品提示“暂无已关联商品可导出”，不生成空文件
保存 / 取消 / 失败保存成功更新关联集合并返回查看；取消或失败保持原关联集合

选择商品和上传沿用同一成功集合；重复项、格式错误、不存在及模拟写入失败项不进入关联结果。商品选择与导入在本轮均以追加演示，不扩展删除或替换规则。CSV保留字符串ID、UTF-8 BOM及标准转义；不提供Excel解析能力。

3. 字段保护

品牌、创券来源、业务场景、卡券分类、名称、图片、面值、发放数量、核销方式、车型、专营店、使用须知、领券/核销时间、结算规则、短信通知等上下文字段保持原有只读值。当前是商城场景，车型与专营店继续展示不适用。

本轮只纠正商品区及导出操作，不改变列表、查看/维护的独立状态或其他场景规则。页面字段来自已读取的留存证据，不代表已还原所有生产分支。

6. 验收要点

1. 查看和维护两页商品区无类型单选、旧汇总和版本块；关联数量准确，四个入口保留。

2. 点击导出直接产生CSV，无任何导出对话框；独立读取文件只有sku_id一列，集合与已关联商品一致。

3. 选择或上传确认仅进入草稿；保存前导出原关联集合，保存后才导出新增成功项；失败与重复项排除。

4. 已投放可保存、刷新恢复；非商品字段不变；空集合和取消有明确反馈。

5. 桌面与390px、标注、file直开、本机HTTP、说明/流程以及离线包可用。
